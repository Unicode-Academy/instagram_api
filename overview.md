# Instagram API

## Yêu cầu kỹ thuật

- ExpressJS + TypeScript + MongoDB
- Cấu trúc API Response

```json
{
  "message": "Nội dung message",
  "data": {},
  "success": true
}
```

- Cấu trúc thông báo lỗi

```json
{
  "message": "Nội dung message",
  "errors": {},
  "success": false
}
```

- Authentication

* JWT + Access Token + Refresh Token + Redis
* OAuth Google
